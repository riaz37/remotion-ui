## Why synthesized, not licensed

The brief asked for a CC0 or Pixabay-licensed 110–125 BPM track. At build
time (2026-09-26):

- Pixabay's music pages returned HTTP 403 to non-browser clients, so a track
  and its license page could not be fetched and recorded verifiably.
- FreePD (CC0) has shut down ("FreePD.com - Site Closed").
- OpenGameArt's CC0 music search had no minimal-electronic match.

Rather than ship audio whose license could not be verified, the score was
composed in code against the film's own beat grid (120 BPM = 15 frames per
beat at 30 fps), which also lets section changes land exactly on camera moves.

## Regenerate

```bash
# from apps/web, with numpy + scipy available
python3 showcase/supabase-demo/scripts/synth.py
```

The generator is seeded (`numpy.random.default_rng(20260926)`), so output is
reproducible.
