<ComponentPage name="drag-drop-flow" preview={DragDropFlowPreview}>

The whole drag beat, not a card sliding into a box. The cursor travels into the
media library, presses the file, and carries it across; the row it left holds its
place as a dashed ghost; the drop zone arms while the file is held over it; and
the release turns into a transfer that fills and completes.

Pass `siblings` to change the rest of the library, `fileName`/`fileSize` for the
file itself, and `speed` to fit the beat into a fixed sequence.
