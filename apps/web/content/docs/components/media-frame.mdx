<ComponentPage name="media-frame" preview={MediaFramePreview} durationInFrames={130}>

The frame opens like a shutter on the media while a slow push runs underneath,
then the title masks up out of its own line and the caption settles beneath.

The frame is cut to `aspect` (16:9 by default) and centred, so `contain` media
fills it instead of sitting in a letterbox, and the layout reserves only what is
shown — with no title and no caption the frame owns the whole safe area.
