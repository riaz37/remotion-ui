---
title: "Text effects"
description: "Animated type for titles, callouts, and captions. Each one is a single primitive you drop into a scene."
---

Text effects animate the letters themselves: typing, decoding, glitching, sweeping light, and morphing between words. They take a string and a few timing props, so they sit inside any scene or composition without extra layout work.
